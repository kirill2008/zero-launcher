# Изменения

## 2.0.2

- VALORANT и League of Legends запускаются, даже если Riot Client открылся на странице игры, но саму игру не начал. Zero Launcher нажимает «Играть» через локальный API клиента. Если клиент ждёт входа в аккаунт, игра запустится сразу после входа (ожидание до трёх минут).
- «Игра запущена» появляется, только когда процесс игры действительно появился. Иначе показывается предупреждение с причиной.
- Steam: в библиотеку попадают только полностью установленные игры, недокачанные и удаляемые пропускаются.
- Файлы настроек и обложек записываются через временный файл, поэтому не портятся при сбое.
- Фоновые задачи корректно останавливаются при выходе.
- Картинки удалённой игры больше не появляются снова, если в момент удаления шла проверка обложек.
- При внутренней ошибке интерфейс подсказывает, где искать подробности: `zero-launcher.log`.
- Проверка в GitHub Actions: тесты на Linux и Windows, сборка `ZeroLauncher.exe`.

## 2.0.1

- Иконка Minecraft Launcher из Microsoft Store и иконки игр Xbox и Game Pass берутся из манифеста приложения.
- Значки из ярлыков `.lnk` и `.url`, из `.exe` и `.dll`, из `.ico` рядом с программой (в том числе для `.jar` и `.bat`).
- Поиск игр EA app, Battle.net и Xbox (папка `XboxGames`).
- Обложки показываются целиком, без обрезки.
- В окне отключены контекстное меню, перетаскивание и браузерные горячие клавиши.
- Стрелки на главной листают игры по одной, в том же порядке, что и карточки.

## 2.0.0

- Новый интерфейс: главная с крупной карточкой игры, библиотека сеткой или списком, «Избранное», «Последние» с журналом запусков, «Статус системы» и «Быстрые действия».
- Обложки, фоны и иконки игр подбираются автоматически (Steam, Epic Games, Riot) и обновляются сами, когда их меняет игра или лаунчер.
- Своя обложка для любой игры и кнопка «Вернуть автоматическую».

## 1.x

Первые версии. До переименования программа называлась Ignite. Библиотека и настройки из них переносятся автоматически.
